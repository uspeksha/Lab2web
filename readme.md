# Lab2Web - Praktikum 2 HTML Lanjutan

Repository ini berisi hasil Praktikum 2 Pemrograman Web tentang HTML Lanjutan.

Di praktikum ini saya belajar dan mencoba beberapa materi HTML, mulai dari tabel, form, input, validasi, semantic HTML, sampai audio dan video.

## Yang saya Pelajari

Beberapa materi yang saya kerjakan di praktikum ini:

* Membuat tabel data mahasiswa
* Membuat tabel menggunakan `thead`, `tbody`, dan `tfoot`
* Menggunakan `caption` dan `colspan`
* Membuat form registrasi
* Menggunakan input text, email, password, date, number, radio, dan checkbox
* Menggunakan `select` dan `textarea`
* Membuat validasi form menggunakan HTML
* Menggunakan `required`, `minlength`, `min`, `max`, dan `type`
* Menggunakan semantic HTML seperti `header`, `nav`, `main`, `section`, `article`, `aside`, dan `footer`
* Menambahkan audio dan video ke halaman HTML
* Membuat mini project Form Biodata Mahasiswa
